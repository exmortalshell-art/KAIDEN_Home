# KAIDEN_Home

Набор Cursor-skills для самоопределения и работы: разобраться, чего хочешь, что умеешь, куда идти и как выбирать вакансии — и отдельно: Inner Lab, чтобы разбирать мысли и укрепляться без псевдопсихологии.

## С чего начать

1. Открой этот репозиторий в [Cursor](https://cursor.com) (веб или приложение).
2. Открой файл **[ИНСТРУКЦИЯ.md](./ИНСТРУКЦИЯ.md)** — там простым языком: какую команду писать и в какой ситуации.
3. В Agent-чате набери слэш-команду — по-английски (`/career-compass`) или по-русски (`/карьерный-компас`). Оба варианта одно и то же.

## Skills в репо

| Команда | По-русски | Зачем |
|---------|-----------|--------|
| `/grill-me` | `/спроси-меня` | Интервью «что я на самом деле хочу / не хочу» |
| `/grilling` | (то же, что спроси-меня) | Ядро интервью; обычно хватает `/спроси-меня` |
| `/career-compass` | `/карьерный-компас` | Направление, разбор вакансии, ревью CV |
| `/profile-builder` | `/собери-профиль` | Собрать профиль из резюме/опыта |
| `/decision-intelligence` | `/помоги-решить` | Сложный выбор (две опции, уходить/оставаться) |
| `/resume-intelligence-hub` | `/карьерный-хаб` | Долгий карьерный хаб (цели, gap, заявки) |
| `/career-ops` | `/поиск-работы` | Оценка офферов, сравнение, трекер, интервью |
| `/career-review-cycle` | `/рабочий-цикл` | Цели, лог работы, brag doc, ревью, повышение |
| `/inner-lab` | `/лаборатория` · `/разберись-в-себе` | Мысли, чекины, Big Five, навыки регуляции (не терапия) |

Черновик карьерного профиля после grilling лежит в `career/profile.md`. Психологические заметки — в `psy/` (в git не попадают).
