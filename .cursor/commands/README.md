# Русские слэш-команды

Официальные имена скиллов Cursor — только латиница (`/grill-me`).
Файлы здесь — **алиасы** для веб- и десктоп-чата: имя файла = то, что пишешь после `/`.

Если кириллица не появилась в меню `/`, напиши ту же фразу текстом
(`спроси меня`, `лаборатория`, `запись мысли`, `психотест`) — агент берёт скилл из `AGENTS.md`.
