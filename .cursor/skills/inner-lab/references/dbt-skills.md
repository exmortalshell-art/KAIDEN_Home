# DBT skills — только навыки

Источник идей: открыто описанные модули Лайнхан (mindfulness, distress tolerance, emotion regulation, interpersonal effectiveness). Это **тренировка навыков**, не индивидуальная DBT, не телефонный коучинг, не работа с пограничным расстройством «по учебнику».

Авторские бланки и длинные скрипты из мануала **не копируй**. Ниже — общеизвестные каркасы своими словами.

## Когда какой навык

| Сейчас | Навык |
|--------|--------|
| Аффект 8–10, тело орёт, сейчас сорвусь / замру | TIPP или заземление, **потом** разговор |
| Импульс сделать то, о чём пожалеешь | STOP |
| Чувство толкает в избегание/вспышку, а факты не требуют этого | Opposite action |
| Нужно попросить / отказать | DEAR MAN (можно репетиция ролей) |
| Путаница «разум vs эмоция» | Wise mind: оба канала, решение не из одного |

## TIPP (острый пик)

Идея: сдвинуть физиологию, не аргумент.

- **T** температура: холод на лицо/запястья, если безопасно (без льда при сердечных противопоказаниях — спроси одной строкой, при сомнении пропусти).
- **I** интенсивное движение 20–60 сек (приседания, выход из комнаты быстрым шагом) — если тело позволяет.
- **P** дыхание: выдох длиннее вдоха, несколько циклов. Не гипервентиляция.
- **P** парное расслабление мышц: сжать 5 сек — отпустить.

Оцени аффект 0–100 до и после. Если не упал — не вини, предложи заземление 5-4-3-2-1 (5 вижу, 4 слышу…).

## STOP

Stop — не действуй по импульсу.  
Take a step back — выйди из переписки / комнаты, если можно.  
Observe — что в теле, какая мысль, какой urge.  
Proceed mindfully — одно следующее действие по ценности, не по жару.

## Opposite action

Только если эмоция **не соответствует фактам** или её действие разрушает ценность.

Примеры (не догма):

- необоснованный стыд → не прятаться, короткий контакт;
- гнев без угрозы → не атаковать, снизить тон, отложить сообщение на 20 мин;
- тревожное избегание бытовой задачи → 10 минут подхода, не «прыжок в пропасть».

Если страх *обоснован* (реальная опасность) — opposite action **не** уместен. Тогда безопасность.

## DEAR MAN (просьба / отказ)

Репетиция: ты — второй человек, коротко, без карикатуры.

- **D** Describe факты без ярлыков  
- **E** Express чувство («мне тревожно», не «ты токсик»)  
- **A** Assert просьбу одним предложением  
- **R** Reinforce чем это даст отношениям / делу  
- **M** Mindful — не уводи в старые войны  
- **A** Appear confident — тон ровный, не извинения за право просить  
- **N** Negotiate — запасной вариант  

GIVE/FAST упоминай только если человек уже в теме; не грузи алфавит.

## Чего не делать под видом DBT

- Разбирать травму «пока навык».
- Обещать, что навык лечит расстройство.
- Стыдить за то, что TIPP «не сработал с первого раза».
- Учить навыкам, когда идёт кризис из `crisis.md`.
