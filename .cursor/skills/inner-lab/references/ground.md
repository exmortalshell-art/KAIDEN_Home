# Заземление / короткий TIPP

Для пика аффекта, когда разбор мысли ещё рано. Не медитация на 40 минут.

1. Оценка аффекта 0–100.
2. Если ≥80 и нет кризиса из `crisis.md` — TIPP из `dbt-skills.md` (температура / движение / выдох длиннее / мышцы).
3. Иначе 5-4-3-2-1: 5 вижу, 4 слышу, 3 касаюсь, 2 запаха или вкуса если есть, 1 дыхание.
4. Оценка после. Если не упало — не вини; предложи встать, воду, холод на запястья, или стоп по `crisis.md`.

Не переходи к детству и не начинай thought record, пока пик не снизился. Короткий файл сессии: до/после, какой навык.
