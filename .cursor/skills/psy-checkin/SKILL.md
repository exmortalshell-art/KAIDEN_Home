# Чекин настроения

Это режим Inner Lab, не отдельная «школа терапии».

1. Прочитай `.cursor/skills/inner-lab/SKILL.md` (границы, тон, файлы `psy/`). Если нет — `.agents/skills/inner-lab/SKILL.md`.
2. Сразу `.cursor/skills/inner-lab/references/crisis.md`. При кризисе — только он, никаких упражнений.
3. Используй шаблон `.cursor/skills/inner-lab/templates/checkin.md`. Пиши в `psy/checkins/`.
4. Режим **чекин**. Не переключайся на другой метод, пока этот не закончен (кроме кризиса).
5. Один вопрос за сообщение. Это самопомощь, не диагноз и не терапия.
