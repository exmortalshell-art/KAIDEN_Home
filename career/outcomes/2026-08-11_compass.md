# Карьерный компас / gap analysis — 2026-08-11

Источник фактов: `career/profile.md` (grilling 2026-08-11).  
CV в `career/cv/` нет — инвентарь способностей опирается на самоописание, не на XYZ-буллеты. Это ограничение ниже помечено.

Рамки: four-gap (`skill / scope / credential / network`) + comp/timing; stretch-target heuristic (1–2 уровня вверх, ~70% match); career capital (Cal Newport).

## Профиль (кто ты как профессионал)

HR с **3+ годами полного цикла подбора**: закрытие вакансий, интервью, атмосфера для новичков, корпоративные праздники, работа с текучестью. Локация **Тула**, переезд не в горизонте. Энергия восстанавливается при **новизне профилей** и куске работы «не только закрыл — забыл»; убивается KPI-конвейером, штрафами, массовым линейным подбором и токсичным микроменеджментом.

**Формула цели уже зафиксирована:** оклад ≥85 000 ₽ на руки + адекватный подбор с новизной (или хороший generalist) + ни одного стоп-флага + силы на своё.

## Stretch target (замок на 1.5–2 года)

| Ось | Значение |
|-----|----------|
| **Роль №1** | Рекрутер / менеджер по подбору **полного цикла**, не конвейер: меняющиеся / более сложные профили, человеческий объём |
| **Запасной** | HR generalist (подбор + адаптация / текучесть / культура / процессы) — если деньги и стоп-флаги ок |
| **Уровень** | Сейчас: mid IC (3+ года). Stretch: **+0–1 уровень** — «сильный полный цикл / senior recruiter» или «generalist в SMB». Не HR BP / Head of HR сразу (+2–3 без доказанного scope) |
| **Компания** | Локальный офис / гибрид в Туле или удалёнка РФ **без стоп-флагов**; размер — скорее SMB / mid-market, где один HR видит людей, а не только воронку |
| **Scope** | Не «N закрытий в неделю любой ценой», а ответственность за качество найма + кусок life-cycle (адаптация / текучесть / культура) |
| **Comp** | Пол **≥85к чистым окладом**; KPI только сверху. Пол «плохо» ~70к |
| **Горизонт** | Посадка в целевой портрет: **12–24 мес.** Этот квартал — инвентарь + фильтрация рынка, не прыжок в другой трек |

### Рыночная триангуляция (Тула / РФ, август 2026)

Ориентиры (агрегаторы смешивают оклад и «от…», массовый и точечный — читать вакансию, не медиану):

- **hh.ru Тула**, выдача «менеджер по подбору / полная занятость» (~86 позиций в выдаче): рядом с целевой планкой встречаются офферы вроде **от 80–85к до вычета**, **от 100к до вычета** (ювелирный бренд), смешанные 70к до вычета / 58–60к на руки. Много шума не-HR в той же выдаче — фильтр обязателен.
- **Rich-List / агрегаты** по «специалист по подбору» в Туле: медиана около **~60к**, средняя по сырым вакансиям часто ниже целевых 85к — значит **85к чистыми = верхняя половина локального рынка**, не «базовая ставка».
- Примеры fingerprint’ов под твой портрет (не офферы «бери сразу»):
  1. *Менеджер по подбору/HR, Самолет Плюс, Тула* — от 85к до вычета; найм в продажи + адаптация + бренд работодателя + корпжизнь. Риск: офис 5/2, продажный найм может скатываться в объём.
  2. *TERRA HR (архив)* — 80–100к на руки; система поиска, воронка, обучение, штат ~200. Ближе к generalist+recruiting.
  3. *HR Generalist remote (talent-move и аналоги)* — до ~130к; 2–3 middle/senior в месяц + онбординг + HR-система. Тянет на запасной трек; конкуренция выше, «гарантия 100–150к» по-прежнему редкость.

**Вывод по деньгам:** цель **85к+ чистым окладом в Туле реалистична как отборная вакансия**, не как медиана. Удалёнка с той же планкой — смотреть, но не строить план на 100–150к гарантии (уже зафиксировано в профиле).

## На что ты уже способна (капитал)

То, что можно честно продавать рынку **после упаковки в цифры**:

| Капитал | Сигнал из профиля | Почему это ценно |
|---------|-------------------|------------------|
| Полный цикл подбора | 3+ года, «закрытие вакансий» | Базовый must-have для роли №1 |
| Интервью | Сильная сторона | Качество найма, не только сорсинг |
| Адаптация / атмосфера для новичков | Явно названо | Мост к generalist и антивыгоранию «не только закрыл-забыл» |
| Текучесть + культура (праздники) | Явно названо | Отличает от чистого hunt’а; career capital шире, чем «закрывальщик» |
| Границы / стоп-флаги | Чёткий список из 5 пунктов | Снижает риск снова сесть в токсичный конвейер |
| Стабильность энергии | 5×8 ок при новизне | Совместимо с устойчивым mid-ростом, не с «геройским» овертаймом |

**T-shape сейчас (черновик):** глубина — **полный цикл рекрутинга + человеческий контур (адаптация/культура)**; ширина — намётки generalist, без доказанной глубины в ТК, компенсациях, L&D, HR-аналитике.

## Чего не хватает — four-gap

| Gap | Item | Severity | Closable |
|-----|------|----------|----------|
| **Skill** | Доказанный опыт **не-линейных / меняющихся / middle+ профилей** (vs массовый линейный) | weighting → почти blocking для роли №1 | 1–2 квартала на упаковку прошлого **или** 1 роль, где это есть в JD |
| **Skill** | Цифры по формуле XYZ: time-to-hire, % выхода на оффер, объём вакансий, снижение текучести | blocking для сильного отклика | **этот месяц** — инвентарь из памяти/отчётов |
| **Skill** | Для generalist-запаса: ТК/кадровый контур, метрики HR, простой процесс адаптации «как система» | weighting | 1–2 квартала (курс + практика на текущем/следующем месте) |
| **Skill** | Инструменты рынка: hh Pro / Авито Работа / прямой поиск / воронка в CRM или таблице | weighting | 1 квартал, если ещё не в привычке |
| **Scope** | Масштаб: размер компании, грейды закрываемых ролей, была ли ответственность за процесс целиком | weighting | нельзя «выучить» — либо всплывёт из прошлого, либо следующий seat |
| **Scope** | Кусок ownership за адаптацию/текучесть **как KPI качества**, не только «праздники» | weighting | ближайшая роль с гибридным JD |
| **Credential** | Резюме / LinkedIn / hh-профиль с метриками | **blocking** для поиска | 1–2 недели после инвентаря |
| **Credential** | Публичных артефактов (кейс, выступление) нет в данных | weighting (не must для mid HR в Туле) | опционально позже |
| **Network** | Тёплые заходы в тульские SMB / знакомые HR / бывшие коллеги | weighting (~10× vs холодный отклик) | continuous с этой недели |
| **Comp / timing** | 85к чистыми = верх локального рынка; много вакансий 50–70к и/или KPI-ловушки | weighting | закрывается **фильтром**, не скиллом |
| **Comp / timing** | Силы на хобби 3–5 ч/нед — нельзя брать роли с вечным авралом | blocking для antivygorania | стоп-флаги на собесе |

### Match ~70%

На целевые JD уровня «полный цикл + кусок адаптации, 80–100к» ты по самоописанию уже в зоне **~60–75%**, если прошлый опыт не был *только* массовым линейным. Если был — skill/scope gap по «сложным профилям» становится главным; тогда generalist в спокойной SMB или точечный подбор в одной функции — честнее, чем притворяться senior niche recruiter.

## 2–4 направления роста

### 1. Основное: полный цикл с новизной (роль №1)
- **Почему:** совпадает с энергией, стоп-флагами и 3+ годами craft.
- **Уже есть:** закрытие, интервью, адаптационный контур.
- **Не хватает:** цифры + доказательства не-конвейерных профилей + резюме.
- **Первый шаг на этой неделе:** выписать 5 закрытых вакансий за последние 12–24 мес. с грейдом/сроком/источником.
- **Доход 1–2 года:** ориентир **80–110к на руки** на отборных локальных/гибридных ролях (источник: витрины hh/careerist Тула, авг 2026); 85к+ чистыми — явная цель-фильтр.
- **Риск:** снова уехать в продажи/розницу с «от 85к», где по факту объём = конвейер.

### 2. Запасное: HR generalist в SMB
- **Почему:** закрывает антивыгорание «не только закрыл-забыл»; рынок Тулы часто клеит подбор+адаптация+культура в одну ставку.
- **Уже есть:** адаптация, текучесть, праздники/культура.
- **Не хватает:** системность (регламенты, метрики), базовый кадровый/ТК-контур, язык generalist в резюме.
- **Первый шаг:** один абзац в резюме «что делала после оффера» (испытательный, чек-ины, текучесть).
- **Доход:** часто **70–100к**; 85к+ достижимо, но отбирать по окладу, не по «оклад+KPI».
- **Риск:** «generalist» = офис-менеджер + подбор без роста.

### 3. Боковой апгрейд (не отдельная карьера): точечный middle-найм / узкая функция
- **Почему:** поднимает rarity career capital без смены трека.
- **Уже есть:** полный цикл; любознательность.
- **Не хватает:** портфель сложных профилей, прямой поиск.
- **Первый шаг:** на следующей роли настоять на 1–2 нелинейных вакансиях в зоне ответственности.
- **Риск:** уйти в агентский hunt с дедлайнами — проверить стоп-флаги.

## Чего НЕ стоит делать

1. **Строить план на удалёнке 100–150к «гарантия»** — редкость; выжигает поиск и обесценивает нормальные 85к локально.
2. **Прыгать сразу в HR BP / «руководитель HR»** — scope gap (команда, P&L, стратегия) не закрыт; это +2 уровня, не stretch 1.
3. **Возвращаться в массовый линейный «лишь бы 80к»** — противоречит всей формуле и стоп-флагам.
4. **Менять трек на «что угодно не HR»** без инвентаря — у тебя уже есть продаваемый craft; сначала упаковать, потом решать о пивоте.

## Чек-реальности

| Горизонт | Что может пойти не так |
|----------|-------------------------|
| **6 мес.** | Без цифр и резюме отклики слабые → усталость → соблазн взять конвейер «на время» |
| **12 мес.** | Локальный рынок тонкий: мало «идеальных» JD → нужен гибрид/осторожная удалёнка + тёплые заходы |
| **24 мес.** | Застрять на 70к без новизны → выгорание и снова «не хочу работать», хотя проблема была в среде, не в факте работы |
