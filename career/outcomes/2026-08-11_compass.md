Рамки: four-gap (`skill / scope / credential / network`) + comp/timing; stretch-target heuristic (1–2 уровня вверх, ~70% match); career capital (Cal Newport).

## Профиль (кто ты как профессионал)

HR с **3+ годами полного цикла** в компании **1С в облаке** (партнёр и франчайзи 1С; ядро — облачный доступ). Штат ~**330**; в поиске **двое** (+ директор по персоналу) — это mid-market IC, не «единственный HR в микро-SMB» и не корпоративный рекрутмент-завод. Формат: **линейный точечный**, мультипрофиль. Локация **Тула**.

**Формула цели:** оклад ≥85 000 ₽ на руки + адекватный подбор с новизной в «своём» контуре (или хороший generalist) + ни одного стоп-флага + силы на своё.

### Энергия по профилям (уточнение)

**Даёт энергию:** техподдержка, бухгалтерия, продуктолог, консультанты (1С).  
**Высасывает:** особенно КЦ и холодный менеджер по продажам; остальное из портфеля — тоже скорее истощает.

Практический вывод: фильтровать JD по стоп-флагам среды **и** по миксу вакансий — если ядро = КЦ/cold sales, роль токсична даже при 85к+. Приоритет работодателей: **1С-партнёры / франчайзи / облачная 1С / смежный B2B-софт и бухсервис**.

**Вывод по деньгам:** total сейчас **~67–72к** (оклад 56 624 + премии до 10–15к). Цель **оклад 85к** ≈ **1.2–1.3× total** — валидный stretch floor, не фантазия. Важно: новый оффер сравнивать с **total**, но требовать **гарантированный оклад ≥85к**, иначе снова сядешь на «оклад 60 + премии если повезёт». Офферы с total ~70к при похожих премиях = латераль. Удалёнка 100–150к окладом — потолок, не план.

## На что ты уже способна (капитал)

То, что можно честно продавать рынку **после упаковки в цифры**:

| Капитал | Сигнал | Почему это ценно |
|---------|--------|------------------|
| Точечный полный цикл | Линейный **точечный**, не конвейер | Прямо бьёт в роль №1 и стоп-флаг «только массовый» |
| Мультипрофиль | 4 частых кластера + 7 редких | Доказывает новизну; не «одна вечная вакансия» |
| Полный цикл до+после оффера | Ведёт кандидата и после оффера по своим вакансиям | Сильный сигнал vs «сорсер до передачи» |
| Параллельный объём | **7–15** вакансий одновременно | Показывает нагрузку mid IC без конвейерной фабрики |
| Срок закрытия | Средний **~1.5 мес.** | Готовая Y в формуле XYZ — вынести в CV |
| Сложные редкие | Старший бухгалтер, продуктолог, СКК, холодный поиск | Зачатки stretch к middle/спецнайму — уже было, не с нуля |
| Интервью + закрытие | Сильные стороны | Качество найма |
| Адаптация / текучесть / культура | Явно названо | Мост к generalist |
| Границы | 5 стоп-флагов | Защита от токсичного конвейера |

**T-shape:** глубина — **точечный полный цикл в экосистеме 1С (облако/партнёр) по ТП–консультантам–буху–product**; ширина — generalist-контур без доказанной глубины в ТК / компенсациях / L&D / аналитике.

## Чего не хватает — four-gap

| Gap | Item | Severity | Closable |
|-----|------|----------|----------|
| **Skill** | Цифры XYZ по кластерам (база уже есть: 7–15 параллельно, ~1.5 мес) — детализация по ТП/1С/бух/продуктолог | **blocking** для сильного отклика | этот месяц |
| **Skill** | Больше **устойчивого** middle/спецнайма (сейчас — «реже», не ядро) | weighting для stretch «сложнее» | 1–2 квартала на след. роли или упаковка редких кейсов |
| **Skill** | Для generalist: ТК/кадры, метрики, адаптация как система | weighting | 1–2 квартала |
| **Skill** | Инструменты: hh Pro / Авито / прямой поиск / воронка | weighting | 1 квартал, если ещё не в привычке |
| **Scope** | Масштаб ~330 / поиск 2+Dir — не gap. Post-hire по своим вакансиям уже есть | — | упаковать в CV как ownership, не как «помогала на праздниках» |
| **Scope** | Нет evidence, что строила **систему** адаптации/текучести на всю компанию (vs свои вакансии) | weighting | generalist-stretch / следующий seat |
| **Credential** | Резюме с портфелем профилей + метриками | **blocking** | 1–2 недели после инвентаря |
| **Network** | Тёплые заходы в тульские SMB / сервисный B2B / бывшие коллеги | weighting | continuous |
| **Comp / timing** | Total ~67–72к → оклад 85к (1.2–1.3×): отборные JD; офферы ~70к total = латераль | weighting | фильтр: оклад ниже ~70к / total без роста — не тратить цикл |
| **Comp / timing** | Бюджет энергии на хобби 3–5 ч/нед | blocking для antivygorania | стоп-флаги |

### Match ~70%

На JD «полный цикл + разные линейные/сервисные профили + кусок адаптации, 80–100к» — уже **~70–80%** по факту портфеля (точечный + мультипрофиль закрывает главный страх «только массовый»).  
Остаётся упаковка и цифры. Stretch к «постоянно middle/IT/редкие спецы» — скорее **~50–60%** без усиления редкого слоя.


## 2–4 направления роста

### 1. Основное: полный цикл внутри экосистемы 1С / облачный B2B
- **Почему:** домен уже есть; энергия = ТП, 1С-консультанты, бух, продуктолог — совпадает с ядром такого бизнеса.
- **Уже есть:** 3+ года в партнёре/франчайзи облачной 1С; мультипрофиль.
- **Не хватает:** цифры; в CV явно писать «1С-облако / франчайзи», не размытое «IT/услуги».
- **Первый шаг:** 4 строки XYZ по энергетическому ядру + одна строка про домен в шапке/саммари резюме.
- **Где искать:** другие 1С-партнёры/франчайзи, облачные 1С, внедренцы, бухсервис на 1С (Тула + РФ remote).
- **Риск:** следующий 1С-партнёр с ядром найма в КЦ/cold sales — домен тот же, энергия снова ноль.

### 2. Запасное: HR generalist в SMB 1С/B2B-софт
- **Почему:** life-cycle + знакомство с продуктовым контуром.
- **Риск:** generalist = офис-менеджер; или SMB без 1С-споріднености и с чужим миксом вакансий.

### 3. Stretch: усилить консультантов / бух / продуктолог внутри 1С-контура
- **Почему:** rarity capital; энергия уже подтверждена.
- **Не хватает:** сделать редкое регулярным на след. месте.
- **Риск:** агентство «любые IT-вакансии» без доменного фокуса.



## Чего НЕ стоит делать

1. **Строить план на удалёнке 100–150к «гарантия»** — редкость; выжигает поиск и обесценивает нормальные 85к локально.
2. **Прыгать сразу в HR BP / «руководитель HR»** — scope gap (команда, P&L, стратегия) не закрыт; это +2 уровня, не stretch 1.
3. **Возвращаться в массовый линейный или в роль, где ядро = КЦ / холодные продажи** — даже за 85к: энергия уже сказала «нет».
4. **В резюме делать героем то, что высасывало** (КЦ, cold sales) только потому что «чаще закрывала» — рынок купит не тот трек.
