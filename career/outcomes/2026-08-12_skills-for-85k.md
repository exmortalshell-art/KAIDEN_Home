# Что нужно для оклада ≥85 000 ₽ на руки — 2026-08-12

Опора: `career/profile.md`. Рынок: tula.hh.ru (выдача «менеджер/специалист по подбору», авг. 2026), архив TERRA HR (80–100к **после** НДФЛ), ориентиры agregatorcursov / Zorky CRM по mid-рекрутеру РФ.

## Главный вердикт

**Новых «магических» скиллов почти не нужно.** Капитал уже mid-level: ~3 года полного цикла, 7–15 вакансий, ~1,5 мес., до+после оффера, HH + E-Staff, мультипрофиль в 1С-контуре.

85к **чистыми** в Туле — верхняя полка локального рынка (часто в выдаче «от 80–85к **до вычета**» ≈ ~70–74к на руки). Значит планка берётся не курсом, а **упаковкой + нишей + доказанной самостоятельностью**.

Пересчёт: «85к до вычета» ≠ «85к на руки». Цель — **гарантированный оклад ≥85к после НДФЛ** (~98к gross при 13%).

## Скиллы: must / nice / не надо

### Must (уже есть или дожать упаковкой)

1. **Полный цикл** заявки → выход → ИС  
2. **Структурированное интервью** + закрытие  
3. **Параллельное ведение** 7–15 позиций  
4. **HH + ATS** (E-Staff)  
5. **Понимание профилей** ТП / 1С-консультант / бух / product-ish  
6. **Работа с заказчиком** вакансии (бриф, ожидания) — обычно есть у full-cycle; если слабо — усилить 1–2 кейсами в рассказе

### Nice (ускоряют оффер на 85к+, не блокер)

- 2–3 метрики: % выхода на оффер, % прохождения ИС, доля закрытий с HH vs прямой поиск  
- Прямой поиск / Telegram / рекомендации (хотя бы «иногда»)  
- Продающий текст вакансии + работа с воронкой (источники → конверсии)  
- Для generalist-трека: базовый ТК/кадры, онбординг как система, 1–2 регламента

### Не нужно для этой планки

- HR BP / стратегия / P&L  
- Английский / международный sourcing  
- IT-хедхантинг senior/lead  
- Курсы «с нуля в HR»  
- Возврат в массовый как «прокачка объёма»

## Два пути к 85к (оба валидны)

### A. Тот же craft, другая упаковка + ниша (быстрее)

Роль: полный цикл в 1С-партнёр / облако / внедрение / бухсервис.  
Срок: при готовом CV и активном поиске — реалистично в горизонте месяцев, не «через год учёбы».  
Главный рычаг: резюме с XYZ + явный домен 1С + фильтр стоп-флагов.

### B. Generalist в SMB той же экосистемы (чуть шире)

Роль: подбор + адаптация/текучесть/культура.  
Добавить: 1–2 доказанных «системных» действия (чек-лист адаптации, учёт текучести, праздники как процесс).  
Риск: generalist = офис-менеджер — читать JD жёстко.

## Чеклист «соответствую ли я 85к»

Отмечай честно:

- [ ] В CV есть: 7–15 параллельно, ~1,5 мес., полный цикл до+после  
- [ ] В саммари явно: 1С / облако / франчайзи (не «IT/услуги»)  
- [ ] Герой портфеля: ТП / консультанты / бух / продуктолог — не КЦ/cold  
- [ ] Есть 1–2 кейса «сложная / новая вакансия»  
- [ ] На собесе умею назвать объём, срок, инструменты, зону ownership  
- [ ] Готова отказать при стоп-флагах (иначе 85к на токсике = откат)

Если 4+ из 6 — **ты уже в зоне оффера**; дальше рынок и переговоры, не «докачка скиллов».

## Ранний опыт: кондитерская фабрика (массовый)

Фиксируем: был массовый подбор на кондитерской фабрике.  
В CV: 1 короткая строка «ранний опыт» или вообще не выносить, если период короткий.  
В интервью: «знаю массовый изнутри — сознательно выбираю точечный». Это усиливает стоп-флаг №5, не противоречит ему.

## Жизненный горизонт (свадьба через 1–1,5 года)

- Локация Тула уже зафиксирована — совпадает с планом.  
- Имеет смысл **закрыть смену работы до свадебного пика**, если поиск всё же разморозится: меньше стресса на двух фронтах.  
- Финансово: цель 85к окладом = подушка под свадьбу + быт; хобби-доход — бонус, не план Б.

## Идеи монетизации хобби (при «не знаю»)

Критерий: 3–5 ч/нед, без KPI-конвейера, можно начать с одной продажи/услуги.

| Идея | Из чего растёт | Первый микрошаг | Реализм денег |
|------|----------------|-----------------|---------------|
| **1. Кастомная вышивка / наборы** | вышивка | 3 фото готовых работ + цена на Авито/VK | низкий старт, растёт с портфолио |
| **2. Черенки / уход за растениями** | растения | объявление «черенки / пересадка / уход на время отпуска» в Туле | быстрые мелкие чеки |
| **3. Мини-группа растяжки / self-care** | растяжка, уход | 4–6 знакомых, 1 сессия/нед за фикс | если комфортно вести людей |
| **4. «Разбор вакансии для кандидата»** | HR-craft | 2–3 платных разбора резюме/собеса знакомым | рядом с работой; границы важны |
| **5. Тру-крайм контент** | интерес | только если тянет писать/говорить регулярно | монетизация долгая; не №1 |

Не выбирать всё сразу. На ближайшие 2 недели достаточно **одного** эксперимента из 1–2.
