# Career profile

Сформировано через `/grill-me` (2026-08-11). Статус: **общее понимание подтверждено**.

## Стартовый симптом

«Кажется, я совсем не хочу работать.»

## Что это на деле

Не отказ от труда. Отказ от **KPI-конвейера, штрафов, микроменеджмента, токсика, массового линейного подбора и вечной одной и той же вакансии**.

5×8 допустим, если можно дышать и есть новизна.

## Целевой портрет (горизонт 1.5–2 года)

| Параметр | Решение |
|----------|---------|
| География | Тула / из Тулы; переезд не планируется |
| Роль №1 | Подбор полного цикла: новые/сложные/меняющиеся профили, человеческий объём (не конвейер) |
| Запасная роль | HR generalist (подбор + адаптация / текучесть / культура / процессы) — брать при деньгах и без стоп-флагов |
| Доход | Оклад **≥85 000 ₽ на руки гарантированно**; KPI/премии только сверху |
| Формат | Гибрид желателен; офис ок при коротком пути и без толпы/большого open space |
| Удалёнка на РФ | Можно смотреть; те же стопы. «100–150к гарантия» почти утопия — не строить план на этом |
| Антивыгорание | И смена профилей, и кусок «не только закрыл–забыл» (люди внутри / порядок в процессе) |
| Параллель | Монетизация хобби важна → работа должна оставлять силы (сейчас исследование 3–5 ч/нед; продукт не зафиксирован) |
| Хобби ≠ зарплата | Растения / вышивка не план на 85к |

## Сильные стороны (уже есть)

- 3+ года в HR, высшее образование
- Полный цикл подбора: закрытие вакансий, собеседования
- Атмосфера для новеньких, праздники, показатели текучести
- Ответственность, лояльность, любознательность

## Что убивало интерес

- Рутина: одни и те же вакансии и одни и те же вопросы
- Неотлаженные процессы как норма
- Давление KPI со штрафами, бесконечная гонка за закрытиями
- Быстрый темп без права передохнуть
- Микроменеджмент, токсичный коллектив/руководство

Свежесть возвращалась, когда профиль вакансии был **совсем другим**.

## Стоп-флаги (автоотказ, даже на высокой вилке)

1. Штрафы / минус из оклада за KPI  
2. Нормы закрытий, от которых выгорают  
3. Хаос процессов как норма («разберёшься на месте»)  
4. Руководитель давит и перебивает уже на собеседовании  
5. Только массовый линейный подбор  

## Нережемое

- Деньги (пол: плохо ниже ~70к; цель оклада ≥85к на руки)  
- Отсутствие токсика и микроменеджмента  

## Критерий одной строкой

> 85к+ чистым окладом + адекватный подбор с новизной (или хороший generalist) + ни одного стоп-флага + силы на своё.

## Добровольная энергия (вне работы)

Вышивка, тру-крайм, уход за комнатными растениями, лёгкая растяжка, уход за собой. Домашние «надо» (уборка, еда) чаще через силу — это не источник смысла.
