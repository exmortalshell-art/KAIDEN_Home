# Профиль (из grilling-сессии)

Обновлено: 2026-08-11. Источник: совместное понимание после `/grill-me`.

## Кто

- Локация: **Тула**, переезд не в горизонте пары лет
- Опыт: **3+ года HR**, полный цикл подбора; сильные стороны — закрытие вакансий, собеседования, атмосфера для новичков, праздники, текучесть
- Формат найма: **линейный точечный** (не массовый конвейер), разные профили
- **Текущий оклад:** 56 624 ₽ **на руки** (после НДФЛ)
- Образование: высшее
- Самоописание: ответственная, лояльная, любознательная

## Портфель закрываемых ролей (2026-08-11)

**Чаще всего**
- 1 линия техподдержки (по сути классическая 2 линия)
- операторы КЦ
- менеджеры по продажам и по сопровождению
- консультанты по 1С

**Реже**
- бухгалтер в группу бухсопровождения клиентов
- менеджер по холодному поиску и привлечению клиентов
- старший бухгалтер
- офис-менеджер
- уборщица
- продуктолог
- специалист отдела контроля качества

### Энергия по профилям (уточнение)

| Даёт энергию | Высасывает |
|--------------|------------|
| техподдержка | особенно **КЦ** |
| бухгалтерия | особенно **холодный менеджер по продажам** |
| продуктолог | остальное из портфеля — скорее истощает |
| консультанты (1С) | |

## Что на самом деле

Стартовое «совсем не хочу работать» = не хочу снова в **KPI-конвейер, штрафы, микроменеджмент, токсик, массовый линейный подбор** и вечную одну и ту же вакансию.  
Сам факт работы и **5×8 ок**, если можно дышать и есть новизна.

## Целевой портрет на 1.5–2 года

| | |
|---|---|
| Роль №1 | Подбор полного цикла, **не конвейер** — новые/меняющиеся/более сложные профили, человеческий объём |
| Запасной | HR generalist (подбор + адаптация/текучесть/культура/процессы) — брать, если деньги и стоп-флаги ок |
| Деньги | **Оклад ≥85 000 ₽ на руки** гарантированно; KPI/премии только сверху, не вместо оклада. Пол «плохо» ~70к |
| Среда | Без штрафов, горящих норм, «хаос — сам разберёшься», давящего руководителя, «только массовый линейный»; короткий путь / не толпа; гибрид желателен, офис рядом ок |
| Антивыгорание | И смена профилей **в зоне ТП / бух / 1С / продуктолог**, и кусок «не только закрыл-забыл» |
| Удалёнка на РФ | Можно смотреть при тех же стопах; «100–150к гарантия» почти утопия — не строить план на этом |
| Параллель | Монетизация хобби важна → работу выбирать так, чтобы оставались силы (исследование 3–5 ч/нед). Хобби ≠ замена 85к |
| Мягкий фильтр по миксу | Если в JD ядро найма = **КЦ или холодные продажи** — скорее отказ, даже при окладе |

## Стоп на собеседовании (автоотказ)

1. Штрафы / KPI минус из оклада  
2. Горящие нормы закрытий  
3. Хаос процессов как норма  
4. Давящий руководитель уже на собесе  
5. Только массовый линейный подбор  

## Хобби / энергия вне работы

Вышивка, растения, тру-крайм, лёгкая растяжка, уход за собой. Дом/еда чаще «надо», не поток.
