# Как пользоваться этим репо

Открой репозиторий **KAIDEN_Home** в Cursor (веб или десктоп).  
В чате Agent напиши команду со слэшем — например `/grill-me`.

Не нужно ставить всё подряд. Выбери одну команду под задачу.

---

## Быстрый выбор: что написать

| Ситуация | Команда | Что получишь |
|----------|---------|--------------|
| «Кажется, не хочу работать» / путаница в голове, ещё нет ясности | `/grill-me` | Жёсткое интервью кругами, пока не станет ясно, чего ты на самом деле хочешь и не хочешь |
| Уже есть мысли, но нужно **направление**: куда расти, какие варианты роли | `/career-compass` | Карьерный разговор + файл с 2–4 направлениями |
| Нашла вакансию — «мне сюда?» | `/career-compass` и вставь ссылку или текст вакансии | Разбор: что подходит / чего не хватает / шансы / что сделать на этой неделе |
| Нужно улучшить резюме | `/career-compass` («посмотри CV») **или** положи файл в `career/cv/` и попроси ревью | Конкретные правки под цель |
| Хочу собрать «кто я по опыту» из резюме/текста в один профиль | `/profile-builder` | Файл `memory/personal_profile.md` |
| Сложный выбор: две вакансии, уходить/оставаться, A или B | `/decision-intelligence` | Разбор по 7 рамкам мышления, без давления «просто выбери» |
| Хочу долгую систему: цели на грейд выше, пробелы в навыках, папка под все отклики | `/resume-intelligence-hub` | Сборка личного «карьерного хаба» в git |
| Активный поиск: оценить оффер, сравнить вакансии, трекер откликов, подготовка к собесу | `/career-ops` | Меню режимов (см. ниже) |
| Уже работаю — цели на год, «чем я занималась», brag doc, 1:1, ревью, повышение | `/career-review-cycle` | Цели, лог работы, документы к ревью |
| Тревожная мысль, самокритика, «разобраться в себе», психотест, чекин настроения | `/inner-lab` | Сессия / запись мысли / Mini-IPIP / навык. Это не терапия и не диагноз |

## Подробнее по командам

### 1. `/grill-me` — разобраться в себе

**Когда:** в начале пути, или когда снова «ничего не хочу» и непонятно почему.

**Как:** напиши `/grill-me` и коротко свою ситуацию одним абзацем.

**Не когда:** если портрет работы уже согласован (он лежит в `career/profile.md`) — лучше идти в `/career-compass` или разбор вакансий.

Внутри вызывается `/grilling` (то же интервью «деревом решений»). Обычно достаточно `/grill-me`.

---

### 2. `/career-compass` — компас, вакансия, CV

**Когда:**
- «Куда мне дальше?» без конкретной вакансии  
- Есть ссылка/текст вакансии  
- Нужно поправить резюме  

**Как:**
1. По желанию положи резюме в папку `career/cv/` (pdf, md или txt).  
2. Напиши `/career-compass` и скажи, что нужно: направление / разбор вакансии / ревью CV.  
3. Отвечай **на один вопрос за раз** — так задумано.

**Файлы:** ответы и разборы появятся в `career/outcomes/`, профиль — в `career/profile.md`.

Уже есть черновик профиля из прошлой сессии — можно сразу сказать: «ориентируйся на `career/profile.md`».

---

### 3. `/profile-builder` — инвентарь опыта

**Когда:** есть резюме или рассказ об опыте, хочешь аккуратный профиль «что умею / где работала».

**Как:**
- Положи файлы в `raw_inputs/profile/` **или** вставь текст в чат  
- Напиши `/profile-builder`

**Результат:** `memory/personal_profile.md`

---

### 4. `/decision-intelligence` — не могу выбрать

**Когда:** два оффера, «generalist или подбор», удалёнка или офис, остаться на 2 года или нет.

**Как:** напиши `/decision-intelligence` и фразу вроде:  
`Новое решение: брать ли вакансию X при окладе 85к и полном офисе`

Агент проведёт через рамки (первые принципы, инверсия, 5 почему, последствия, сожаление, цена отказа, премортем). Сессии пишутся в `sessions/`.

---

### 5. `/resume-intelligence-hub` — большая система надолго

**Когда:** хочешь не разовый совет, а репозиторий: цель на 1–2 ступени выше, матрица навыков, истории STAR, папки под каждую заявку.

**Как:** `/resume-intelligence-hub` и скажи «хочу собрать хаб» / «gap analysis» / «подготовить отклик под JD».

Это тяжелее остальных — бери, если готова вести папки постоянно. Для быстрого ответа чаще хватит `/career-compass`.

---

### 6. `/career-ops` — поиск работы «как операционка»

**Когда:** уже ясно, что ищешь (см. `career/profile.md`), и нужна оценка вакансий, сравнение, трекер, подготовка к интервью.

**Как:** напиши `/career-ops` — покажет меню. Частые варианты:

| Написать | Задача |
|----------|--------|
| `/career-ops` | Меню всех режимов |
| `/career-ops` + текст или ссылка на вакансию | Полный разбор «подходит / не подходит» |
| `/career-ops oferta` | Только оценка по шкале, без лишнего |
| `/career-ops ofertas` | Сравнить несколько вакансий |
| `/career-ops interview-prep` | Подготовка к собеседованию в конкретную компанию |
| `/career-ops interview/practice` | Тренировка ответов по одному вопросу |
| `/career-ops tracker` | Статусы откликов |
| `/career-ops titles` | Какие ещё названия должностей смотреть |
| `/career-ops upskill` | Где дыры в навыках по уже разобранным вакансиям |

В репо уже прописаны твои стоп-флаги и зарплатный пол (`modes/_profile.md`, `modes/_custom.md`) — разборы должны их учитывать.

**Важно:** режимы вроде массового скана порталов и авто-PDF рассчитаны на полный проект career-ops (скрипты Node). В Cursor web спокойно работают **разбор текста/ссылки, сравнение, интервью-подготовка, логика оценки**. Если сканы/PDF не взлетят — используй `/career-compass` для одной вакансии.

---

### 7. `/career-review-cycle` — когда уже на месте

**Когда:** не поиск, а текущая работа: цели на год, «что сделать к 1:1», brag doc, самооценка к ревью, кейс на повышение.

**Как:** `/career-review-cycle` и своими словами, например:  
«Запиши, что я закрыла сложную вакансию за 2 недели»  
«Подготовь меня к 1:1 завтра»  
«Собери brag doc за квартал»

Файлы складываются в папку `vault/`.

---

### 8. `/inner-lab` — разобраться в себе без инстаграм-психологии

**Когда:** крутится мысль, самокритика, прокрастинация как избегание, «кто я», хочется чекин или нормальный Big Five — не MBTI.

**Как:** `/inner-lab` и одно предложение, что сейчас. Или сразу: «запись мысли», «тест Big Five», «чекин», «ценности», «навык, я сейчас на взводе».

**Что получишь:** короткий разговор (один вопрос за раз) + файл в `psy/` (сессия, thought record, тест). Личные файлы в gitignore.

**Не когда:** выбор вакансии (это `/career-compass`), угроза жизни (сначала живые службы, скилл сам уйдёт в протокол кризиса), «проработай мне травму / поставь диагноз».

Внутри только методы с опорой на данные: CBT, ACT, навыки DBT, MI, Mini-IPIP. Явный отказ от MBTI, эннеаграммы, манифестации, NLP-как-терапии. Список источников: `.agents/skills/inner-lab/references/sources.md`.

## Рекомендуемый порядок (не обязательно)

1. Если ещё мутно в голове → `/grill-me`  
2. Зафиксировать опыт → резюме в `career/cv/` + `/profile-builder` или `/career-compass`  
3. Понять направление / проверить вакансию → `/career-compass`  
4. Застряла между двумя вариантами → `/decision-intelligence`  
5. Пошёл активный поиск → `/career-ops`  
6. Вышла на работу и хочешь не потерять год → `/career-review-cycle`  
7. Хочешь «всё в одной системе на годы» → `/resume-intelligence-hub`  
8. Мысли/настроение/самотест, не вакансии → `/inner-lab`

## Полезные папки

| Папка | Зачем |
|-------|--------|
| `career/profile.md` | Твой рабочий портрет (уже заполнен черновиком) |
| `career/cv/` | Сюда клади резюме |
| `career/vacancies/` | Сохранённые описания вакансий |
| `career/outcomes/` | Итоги сессий career-compass |
| `raw_inputs/profile/` | Сырьё для profile-builder |
| `memory/` | Личный профиль после profile-builder |
| `sessions/` | Сессии decision-intelligence |
| `vault/` | Цели/логи/brag для career-review-cycle |
| `psy/` | Inner Lab: сессии, записи мыслей, тесты (приватное) |
| `data/pipeline.md` | Список URL вакансий для career-ops |
| `modes/` | Правила оценки вакансий (стопы, язык) |

## Коротко

- Путаница, чего хочу **на работе** → `/grill-me`  
- Крутятся мысли / настроение / Big Five → `/inner-lab`  
- Куда идти / эта вакансия / CV → `/career-compass`  
- Собрать профиль из опыта → `/profile-builder`  
- Не могу выбрать → `/decision-intelligence`  
- Активный поиск пачкой → `/career-ops`  
- Уже работаю, коплю доказательства → `/career-review-cycle`  
- Хочу большую систему → `/resume-intelligence-hub`  
- Мысли, тесты, навыки, не вакансии → `/inner-lab`
