# House rules (career-ops)

- Write all human-facing output in **Russian**.
- Treat `career/profile.md` as the source of truth for constraints when present.
- Never recommend an offer that violates hard stop-flags in `_profile.md`.
- Prefer Tula / hybrid / short commute; do not push relocation.
- Base salary ≥ 85k RUB net is a hard floor for "recommend apply"; below that only if user explicitly asks to consider.
- Hobbies (embroidery, plants) are life/side income research — not a substitute for the salary floor.
