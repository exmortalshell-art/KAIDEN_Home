# Inner Lab — личные заметки

Сюда агент пишет сессии, записи мыслей, чекины и тесты.

**Не коммить содержимое.** В git должны быть только этот README, пример профиля и пустые папки. Живые файлы в `.gitignore`.

## Как начать

В Agent-чате Cursor:

```
/inner-lab
```

или своими словами: «разбери мысль, что я всех подвожу», «пройдём Big Five», «чекин за сегодня».

Первая сессия: коротко, что сейчас жмёт (без романа). Дальше — один вопрос за раз.

## Что сюда кладётся

| Папка / файл | Что |
|--------------|-----|
| `profile.md` | Устойчивый автопортрет (создаётся из шаблона скилла) |
| `summary.md` | Короткая сводка для следующей сессии |
| `sessions/` | Разборы |
| `records/` | CBT thought records |
| `checkins/` | Настроение / сон / энергия |
| `tests/` | Mini-IPIP, скрининги |

Шаблон профиля: `.agents/skills/inner-lab/templates/profile.md` (копия в `.cursor/skills/inner-lab/`).

## Это не терапия

ИИ не ставит диагнозы, не лечит травму и не заменяет психиатра. При мыслях о смерти — живые службы, не этот каталог файлов. Номера и правила — в скилле, `references/crisis.md`.
